\begin{abstract}
Tensor-train policy iteration (TTPI) makes hybrid control tractable by replacing
full state-action tensors with low-rank tensor trains, but its cost remains
sensitive to the ranks induced by sequential tensor unfoldings. This paper
studies action-mode ordering as an explicit algorithmic variable in TTPI. We
argue that physics-aware adjacency is a useful prior but not a sufficient
objective: weighted linear arrangement measures cumulative cut burden, whereas
peak memory and TT-Cross workload are driven by cut-level rank bottlenecks. We
therefore formulate block-preserving and rank-aware mode reordering objectives
for hybrid actuator pairs, together with diagnostics that record TT-Cross query
requests, transient rank profiles, memory, runtime, and singular-spectrum
proxies. The current repository-synchronized results support a resource
sensitivity claim and define the evidence required before making stronger
control-performance claims.
\end{abstract}
