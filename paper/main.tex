\begin{abstract}
Tensor-train policy iteration (TTPI) represents high-dimensional hybrid
state-action functions through sequential low-rank factorizations. Although
permuting action variables preserves the underlying joint action space, it
changes TT unfoldings and can substantially alter TT-Cross workload, peak
memory, and out-of-memory behavior. This paper studies action-mode ordering as a
first-class algorithmic variable in TTPI. We introduce a deterministic
block-preserving coupling-aware ordering strategy that keeps the continuous and
discrete variables of each actuator adjacent while arranging actuator blocks by
structural coupling. We evaluate orderings with diagnostics for TT-Cross query
requests, transient cut-rank profiles, memory, runtime, completion probability,
and completed-run control performance. Current RTX 5080 prestudy results on
HardMove HM8/HM12 indicate that the coupling-aware ordering implemented as
\texttt{sensitivity\_pam} provides the most stable resource profile among the
tested candidates, whereas a static cumulative rank proxy and a naive
physics--sensitivity mixture do not reliably predict dynamic TT-Cross burden.
\end{abstract}
